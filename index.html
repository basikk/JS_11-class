Урок 1: Основи HTML — Проєктування корпусу

Вітаємо на верфі, Командире! Будь-який космічний крейсер починається з креслення. У веб-розробці таким кресленням і одночасно силовим каркасом виступає HTML (HyperText Markup Language — мова гіпертекстової розмітки).

1. Базова структура документа (Фундамент корабля)

Кожен сайт має стандартну структуру блоків, як і відсіки нашого корабля. Без них система не запуститься.

<!DOCTYPE html>
<html>
  <head>
    <title>Термінал Orion</title>
  </head>
  <body>
    <!-- Тут розміщується екіпаж та обладнання -->
  </body>
</html>
  • <!DOCTYPE html> — Системний протокол. Повідомляє браузеру, що ми будуємо за сучасними стандартами HTML5.
  • <html> — Зовнішня титанова обшивка. Цей тег обгортає абсолютно весь код на сторінці.
  • <head> — Бортовий комп'ютер. Містить технічні дані (назву вкладки <title>, шрифти), які приховані від очей пасажирів.
  • <body> — Житлові відсіки. Усе, що написано всередині цього тегу, відобразиться на екрані монітора.

2. Робота з текстом (Бортові записи)

Щоб вивести інформацію на екран, нам потрібні текстові теги. Основні з них — це заголовки та параграфи.

Заголовки (Рівні доступу)

В HTML існує 6 рівнів заголовків: від <h1> (найбільший та найважливіший) до <h6> (найменший). Правило: на одній сторінці має бути лише один <h1> — це головна назва!

<h1>Крейсер Orion</h1>
<h2>Відсік двигунів</h2>
<h3>Панель управління тягою</h3>

Параграфи (Стандартні повідомлення)

Для звичайного тексту, описів та статей використовується тег <p> (від слова paragraph). Він автоматично робить відступи зверху та знизу.

<p>Системи життєзабезпечення працюють у штатному режимі.</p>
<p>Рівень кисню: 98%.</p>

3. Форматування тексту (Модифікатори даних)

Іноді в бортовому журналі потрібно виділити критичну помилку або зробити акцент. Для цього є спеціальні теги, які пишуться всередині параграфів.

  • <strong> або <b> — Робить текст жирним (виділення важливого).
  • <em> або <i> — Робить текст курсивним (акцент голосом).
  • <u> — Підкреслений текст.
  • <s> або <del> — Перекреслений текст (старі дані).
  • <br> — Примусовий розрив рядка (як Enter). Не має закриваючого тегу!
  • <hr> — Горизонтальна лінія. Візуальний розділювач відсіків.
<p>Увага! Виявлено <strong>критичну поломку</strong> корпусу.<br>
Прохання екіпажу <s>панікувати</s> зберігати <u>спокій</u>.</p>
<hr>

Урок 2: Відсіки корабля — Containers & Semantics

На першому етапі ми створили основу. Тепер час розділити внутрішній простір крейсера на функціональні зони. Без чіткого планування екіпаж заблукає, а бортовий комп'ютер (браузер) не зрозуміє, де знаходиться місток, а де — паливний склад.

1. Універсальні блоки: <div> та <span>

Це "пусті" контейнери, які ми використовуємо для групування елементів. Самі по собі вони не мають стилю, але вони — незамінні інструменти інженера.

<div> (Блок-відсік)

Це велика кімната. Він займає всю ширину доступного простору і завжди починається з нового рядка.

<div>Відсік двигуна</div>

<span> (Деталь/Індикатор)

Це маленька деталь всередині кімнати. Він займає рівно стільки місця, скільки потрібно, і не перериває рядок.

<span>Датчик тиску</span>

2. Семантика: Навігаційна карта корабля

Раніше інженери будували все лише з <div>. Це було схоже на корабель, де на кожних дверях написано просто "Кімната". Семантичні теги дають кожній зоні унікальне ім'я, зрозуміле для пошукових систем та систем доступності.

<header> — Капітанський місток. Тут логотип, назва корабля та головне меню.
<nav> — Система навігації. Список посилань для переміщення між палубами.
<main> — Головна палуба. Тут розміщується основний унікальний контент уроку чи сторінки.
<section> — Спеціалізований цех. Групує пов'язаний за темою контент (наприклад, "Технічні характеристики").
<footer> — Технічний трюм. Контактна інформація, копірайт та посилання на соцмережі флоту.

Приклад семантичної архітектури:

<header>
      <img src="logo.png" alt="Orion Logo">
      <nav>Посилання на палуби</nav>
  </header>

  <main>
      <section>
          <h2>Стан реактора</h2>
          <p>Реактор працює стабільно.</p>
      </section>
  </main>

  <footer>
      <p>&copy; 2124 Orion Fleet Academy</p>
  </footer>

Урок 3: Навігаційні системи

Для керування складним крейсером нам потрібні чіткі переліки обладнання та канали зв'язку. Сьогодні ми опануємо списки для інвентаризації та посилання для міжпросторових переходів.

1. Списки: Інвентаризація та Протоколи

В HTML списки дозволяють групувати пов'язані дані. Це основа для створення меню навігації та переліку характеристик корабля.

<ul> (Unordered List)

Маркований список. Використовується, коли порядок елементів не має значення (наприклад, склад запчастин).

<ul>
      <li>Плазмова гармата</li>
      <li>Щитовий генератор</li>
    </ul>

<ol> (Ordered List)

Нумерований список. Ідеальний для покрокових інструкцій та алгоритмів запуску систем.

<ol>
      <li>Розігрів реактора</li>
      <li>Перевірка палива</li>
    </ol>

Кожен окремий пункт списку обов'язково загортається в тег <li> (List Item).

2. Гіперпосилання: Гіперпросторові стрибки

Тег <a> (anchor — якір) створює зв'язок між сторінками. Це "портал", який миттєво переносить користувача в іншу локацію.

Анатомія посилання:

<a href="https://fleet-academy.com" target="_blank">База флоту</a>
  • href — (Hypertext Reference) Координати цілі. Це адреса сторінки, куди веде посилання.
  • target="_blank" — Команда відкрити портал у новому вікні (терміналі), не закриваючи поточний.
  • Текст посилання — Те, на що пілот натискає в інтерфейсі.

Урок 4: Бортові журнали та Таблиці даних

Для керування космічним флотом недостатньо простого тексту. Нам потрібні матриці даних. В HTML для цього використовуються таблиці, які дозволяють впорядкувати інформацію по рядках та стовпчиках.

1. Анатомія таблиці: Основні вузли

Таблиця будується за принципом вкладеності. Уявіть це як сітку енергоблоків, де кожен елемент має своє чітке місце.

  • <table> — Головний контейнер, що обгортає всю таблицю.
  • <tr> — (Table Row) Горизонтальний рядок таблиці.
  • <th> — (Table Header) Комірка заголовка. Текст у ній зазвичай жирний і центрований.
  • <td> — (Table Data) Звичайна комірка з даними.

Приклад простої таблиці екіпажу:

<table border="1">
      <tr>
        <th>Позивний</th>
        <th>Статус</th>
      </tr>
      <tr>
        <td>Orion-1</td>
        <td>У польоті</td>
      </tr>
    </table>

2. Об'єднання відсіків (colspan та rowspan)

Іноді одна система займає кілька секторів. В таблицях ми можемо об'єднувати комірки за допомогою спеціальних атрибутів:

colspan (Горизонтально)

Дозволяє одній комірці розтягнутися на кілька стовпчиків.

<td colspan="2">Загальна потужність</td>

rowspan (Вертикально)

Дозволяє комірці розтягнутися на кілька рядків.

<td rowspan="3">Сектор А</td>

3. Семантика таблиць: Заголовок та Групування

Для складних журналів ми використовуємо додаткові теги, щоб браузер розумів структуру даних:

  • <caption> — Назва таблиці (відображається над нею).
  • <thead> — "Голова" таблиці (група заголовків).
  • <tbody> — Основне "тіло" з даними.
  • <tfoot> — "Підвал" таблиці (підсумки, фінальні розрахунки).

🛠 Практикум: "Реєстр озброєння"

Рівень 1: Базовий звіт

Створіть таблицю на 2 рядки та 2 стовпчики: "Тип зброї" та "Потужність". Заповніть один рядок даними (наприклад: Лазер — 500ТВт).

Рівень 2: Розширений лог (th + caption)

Додайте до таблиці назву через <caption> та зробіть верхній рядок заголовками за допомогою <th>. Додайте третій стовпчик "Статус енергії".

Додайте в кінець таблиці додатковий рядок, де одна комірка буде об'єднана на всі три стовпчики (colspan="3") з текстом "Всі системи працюють стабільно".

Урок 5: Мультимедійні системи — Аудіо та Відео

Для повноцінного функціонування містка Orion нам потрібні системи оповіщення та візуального моніторингу. HTML дозволяє інтегрувати медіафайли безпосередньо в інтерфейс без сторонніх плагінів.

1. Бортовий інтерком: Тег <audio>

Використовується для відтворення звукових протоколів, сигналів тривоги або фонової атмосфери у кают-компанії.

<audio src="alarm.mp3" controls>
  Ваш термінал не підтримує аудіосистеми.
</audio>
  • controls — Додає панель керування (Play/Pause, гучність). Без цього атрибута плеєр буде невидимим.
  • autoplay — Запуск відразу після завантаження (браузери часто блокують це без вимкненого звуку).
  • loop — Нескінченне відтворення сигналу.
  • muted — Початковий запуск без звуку.

2. Відеоспостереження: Тег <video>

Урок 7: Подача живлення — Знайомство з CSS

HTML — це структура, але без CSS наш корабель виглядає як чорно-біле креслення. CSS дозволяє нам керувати кольорами, шрифтами та розміщенням елементів, створюючи справжній космічний інтерфейс.

1. Підключення живлення: Як додати CSS

Щоб "заживити" стилі, ми використовуємо тег <link> всередині блоку <head> нашої сторінки. Це створює канал зв'язку між HTML та окремим файлом зі стилями.

<!-- Додається в <head> -->
<link rel="stylesheet" href="style.css">

2. Селектори: Націлювання на системи

Щоб стилізувати елемент, ми повинні його "вибрати". В CSS є три основні типи селекторів:

За тегом (Tag)

Змінює всі елементи цього типу на кораблі.

p {
                  color: grey; /* Весь текст */
                }

За класом (Class)

Для групи елементів. Позначається крапкою .

.btn-glow {
                    color: cyan; /* Тільки кнопки */
                  }

За ID (Unique)

Тільки для одного об'єкта. Позначається решіткою #

#main-reactor {
                      background: red;
                    }

3. Базова стилізація: Світло та Шрифти

  • color — встановлює колір тексту (можна назвами: white, або кодами: #00ff00).
  • background-color — колір фону відсіку.
  • font-family — вибір "космічного" шрифту (наприклад, Arial, sans-serif).
  • font-size — розмір символів на моніторі.
body {
  background-color: #0b0e14; /* Темний космос */
  color: #e0e0e0;            /* Світлий текст */
  font-family: 'Segoe UI', sans-serif;
}

Урок 8: Бронювання та Габарити — Box Model

Уявіть, що кожен елемент вашого крейсера — це вантажний контейнер. Щоб він не розчавив сусідні модулі та мав захисний шар, ми використовуємо чотири компоненти блокової моделі.

1. Анатомія блоку: Від ядра до обшивки

Кожен елемент складається з чотирьох зон, які вкладаються одна в одну:

  • Content (Вміст): Ядро системи. Текст, зображення або інший блок. Його розміри задаються через width та height.
  • Padding (Внутрішній відступ): Теплоізоляція. Простір між вмістом та бронею. Він збільшує розмір блоку "всередині".
  • Border (Межа): Бронеплита. Лінія, що оточує вміст та відступи. Має товщину, стиль та колір.
  • Margin (Зовнішній відступ): Безпечна дистанція. Простір між цим блоком та іншими об'єктами на палубі.

2. Керування розмірами: Властивості

В CSS ми можемо налаштовувати кожну сторону окремо або всі разом:

Приклад налаштування модуля:

.engine-room {
  width: 300px;         /* Ширина ядра */
  padding: 20px;        /* Відступ з усіх боків */
  border: 5px solid gold; /* Товщина, тип, колір межі */
  margin: 50px;         /* Дистанція до інших модулів */
}

Скорочений запис (Shorthand):

Замість того, щоб писати margin-top, margin-right і т.д., можна використати правило "годинникової стрілки" (Верх -> Право -> Низ -> Ліво):

padding: 10px 20px 15px 5px; /* Вказано всі сторони окремо */
margin: 20px auto;           /* Верх/Низ: 20px, Право/Ліво: по центру */

3. Головна проблема інженерів: box-sizing

За замовчуванням браузер додає padding та border до заданої ширини. Тобто блок 100px з падінгом 20px стане шириною 140px. Це може зруйнувати корпус корабля!

content-box (Стандарт)

Розмір збільшується. Важко розраховувати габарити.

border-box (Рекомендовано)

Падінги та межі "з'їдають" місце всередині, не змінюючи загальну ширину блоку.

Золоте правило інженерії: Завжди встановлюйте це на початку розробки:

* {
  box-sizing: border-box;
}

Урок 9: Flexbox — Системи автоматичного позиціонування

Раніше інженери витрачали години, щоб вирівняти блоки по центру. Flexbox вирішує це миттєво. Він робить контейнер "гнучким", дозволяючи елементам всередині розширюватися, стискатися та вирівнюватися за заданими осями.

1. Активація Flex-контейнера

Щоб система запрацювала, ми повинні призначити батьківському елементу (палубі) властивість display: flex;. Тепер усі прямі нащадки стають "гнучкими елементами" (flex-items).

.deck {
  display: flex; /* Магія починається тут */
  gap: 20px;     /* Дистанція між модулями */
}

2. Головна та Поперечна осі

Flexbox працює у двох вимірах. Ви повинні розуміти, куди спрямований потік енергії:

  • flex-direction: row; — (За замовчуванням) Елементи йдуть один за одним зліва направо (горизонтальна палуба).
  • flex-direction: column; — Елементи йдуть зверху вниз (вертикальна ліфтова шахта).

3. Вирівнювання: Justify та Align

Це головні інструменти для точного націлювання модулів:

justify-content

Керує вирівнюванням по головній осі (зазвичай горизонтально).

  • flex-start — у лівий край.
  • center — точно по центру.
  • space-between — розштовхати до країв.

align-items

Керує вирівнюванням по поперечній осі (зазвичай вертикально).

  • flex-start — до стелі.
  • center — по центру висоти.
  • stretch — розтягнути на всю висоту.

Урок 10: Неонове підсвічування та Візуальні ефекти

Сучасний інтерфейс крейсера Orion має бути не лише функціональним, а й приємним для ока пілота. Ми використаємо закруглення, тіні та градієнти, щоб створити ефект скляних голографічних екранів.

1. Обтічність корпусу: border-radius

У космосі гострі кути — це зайвий опір (принаймні в атмосфері). Властивість border-radius дозволяє закругляти краї блоків.

.panel {
  border-radius: 15px; /* Легке закруглення */
}

.porthole {
  width: 100px;
  height: 100px;
  border-radius: 50%; /* Перетворює квадрат на ідеальне коло (ілюмінатор) */
}

2. Енергетичне сяйво: box-shadow

Щоб створити ефект неону або глибини, ми використовуємо тіні. Тінь може бути як зовнішньою (світіння), так і внутрішньою (втиснута панель).

Синтаксис тіні:

box-shadow: [X-зміщення] [Y-зміщення] [Розмиття] [Розтягування] [Колір]; 
.neon-btn {
  /* Тінь без зміщення, але з великим розмиттям створює сяйво */
  box-shadow: 0 0 15px #00f2ff; 
}

.inner-panel {
  /* Ключове слово inset робить тінь внутрішньою */
  box-shadow: inset 2px 2px 10px rgba(0, 0, 0, 0.5);
}

3. Гіперпросторові переливи: Gradients

Замість пласких кольорів ми використаємо градієнти. Це плавний перехід від одного кольору до іншого.

Linear Gradient

Лінійний перехід (наприклад, зверху вниз або під кутом).

background: linear-gradient(to right, #1e3c72, #2a5298);

Radial Gradient

Розходиться колами від центру (ефект прожектора).

background: radial-gradient(circle, #333, #000);

Урок 11: Оживлення систем — :hover та Transition

Навіть найпотужніша броня має бути зручною. Псевдоклас :hover дозволяє елементам реагувати на наближення курсору, а властивість transition робить цю реакцію плавною та приємною для ока пілота.

1. Сенсор наближення: Псевдоклас :hover

Це спеціальний стан елемента, який активується, коли миша знаходиться над ним. Це ідеально підходить для підсвічування кнопок або розгортання додаткової інформації.

.control-button {
  background-color: #222;
  color: white;
}

/* Стан при наведенні */
.control-button:hover {
  background-color: #00f2ff; /* Змінюємо колір на неоновий */
  cursor: pointer;           /* Змінюємо вигляд курсору на "руку" */
}

2. Гідравліка інтерфейсу: Властивість transition

Без анімації колір змінюється миттєво. Властивість transition (перехід) дозволяє розтягнути цю зміну в часі, створюючи ефект плавної роботи механізмів.

Синтаксис плавного переходу:

transition: [властивість] [час] [функція] [затримка]; 
.nav-link {
  color: grey;
  /* Плавна зміна кольору протягом 0.3 секунди */
  transition: color 0.3s ease-in-out;
}

.nav-link:hover {
  color: #00f2ff;
}

Порада: Завжди пишіть transition у основному стані елемента, а не в :hover. Це забезпечить плавність і при наведенні, і коли миша покидає елемент.

3. Часові функції (Timing Functions)

Як саме рухається анімація? Ми можемо налаштувати динаміку процесу:

  • linear — Рівномірна швидкість (механічно).
  • ease-in — Повільний старт, швидкий фініш.
  • ease-out — Швидкий старт, плавна зупинка (найприродніше для інтерфейсів).
  • ease-in-out — Плавний старт і плавний фініш.

Урок 12: Автономні системи та Класи-стани

На попередніх уроках ми навчили корабель реагувати на пілота. Сьогодні ми підемо далі: створимо автономні анімації, що працюють постійно, та закладемо логіку "бойових режимів", які активуються майбутнім JavaScript-кодом.

1. Автономні анімації: @keyframes

Якщо transition потребує тригера (наприклад, наведення миші), то @keyframes дозволяє створити цикл, який працює сам по собі. Це ідеально для пульсації реактора або руху зірок за ілюмінатором.

Як це працює:

  1. Спочатку описуємо сценарій через @keyframes [назва].
  2. Вказуємо стани (0% — початок, 100% — кінець, або проміжні точки).
  3. Призначаємо цей сценарій елементу через властивість animation.
/* Сценарій пульсації */
@keyframes reactor-glow {
  0% { box-shadow: 0 0 5px blue; }
  50% { box-shadow: 0 0 25px cyan; }
  100% { box-shadow: 0 0 5px blue; }
}

.core {
  animation: reactor-glow 3s infinite ease-in-out;
}

1. Що таке JavaScript і навіщо він потрібен?

Уяви, що створення сайту — це збирання робота:

  • HTML — це металевий каркас (голова, руки, тулуб).

Без JS сайти були б просто статичними картинками (як газета). Завдяки JS працюють лайки в Instagram, коментарі на YouTube, браузерні ігри, анімації та калькулятори.

2. Як підключити JS до сторінки?

Щоб браузер зрозумів, що ти написав код JavaScript, його потрібно правильно підключити до HTML-файлу. Найкращий спосіб — створити окремий файл (наприклад, script.js ) і підключити його перед закриваючим тегом </body> за допомогою тега <script> :

    <!-- Підключаємо наш JS файл у самому кінці -->
    <script src="script.js"></script>

</html>

Урок 2: Змінні та типи даних 📦

1. Що таке змінні?

Уяви, що змінна — це коробка з наклейкою. Ти можеш покласти туди будь-що (число, текст), а наклейка — це назва змінної, за якою ти потім знайдеш цю коробку.

У сучасному JavaScript для створення таких "коробок" використовують два слова: let та const .

2. let та const: у чому різниця?

  • let — це звичайна коробка. Ти можеш будь-коли дістати звідти значення і покласти нове.
  • const (константа) — це сейф. Якщо ти поклав туди значення, змінити його вже неможливо . 
let score = 10; // Створили змінну
score = 15;     // Змінили її значення (це ок)

const playerName = "Олексій";
// playerName = "Іван"; // ПОМИЛКА! Константу змінювати не можна

Золоте правило: Завжди використовуй const . Використовуй let лише тоді, коли точно знаєш, що значення буде змінюватись (наприклад, рахунок у грі чи вік).

3. Основні типи даних

Комп'ютер повинен розуміти, з чим він працює: з текстом чи з математикою. Тому існують типи даних.

🔢 Number (Числа)

Будь-які числа: цілі або дробові. З ними можна робити звичайну математику. 

const age = 16;
const price = 99.99;
const total = age + 10; // 26

🔤 String (Рядки тексту)

Текст завжди береться в лапки: одинарні ' ' або подвійні " " . Немає різниці, які використовувати. 

const greeting = "Привіт!";
const city = 'Київ';

✨ Суперфішка: Шаблонні рядки (зворотні лапки ` ` )

Це найзручніший спосіб об'єднувати текст та змінні. Використовуй символ долара $ та фігурні дужки {} , щоб вставити змінну прямо всередину тексту: 

const name = "Марія";
const apples = 5;

// Сучасний і дуже зручний спосіб:
console.log(`Привіт, мене звати ${name}, і в мене є ${apples} яблук.`);

✅ Boolean (Логічний тип)

Має лише два значення: true (правда) або false (брехня). Часто використовується для перевірок: чи увімкнене світло, чи авторизований користувач. 

const isGameOver = false;
const isUserLoggedIn = true;

Урок 3: Умовні оператори (if, else) та логіка 🔀

1. Що таке розгалуження?

Уяви своє життя: " Якщо на вулиці дощ, я візьму парасольку. Інакше — одягну сонцезахисні окуляри". Ти постійно приймаєш рішення на основі певних умов.

Програми роблять те саме! Вони не завжди виконують код рядок за рядком зверху вниз. Іноді комп'ютеру потрібно "розділити шлях" залежно від ситуації. Для цього в JavaScript використовують умовні оператори.

2. Оператор if (Якщо)

Це базовий спосіб сказати браузеру: "Виконай цей шматок коду ТІЛЬКИ в тому випадку, якщо умова є правдою ( true )". 

const age = 16;

// Перевіряємо умову в круглих дужках ()
if (age >= 18) {
    // Цей код у фігурних дужках {} виконається, ТІЛЬКИ якщо age 18 або більше
    console.log("Доступ дозволено! Вітаємо у грі.");
}

Оскільки в нашому прикладі age дорівнює 16, умова 16 >= 18 є брехнею ( false ). Тому код у фігурних дужках просто проігнорується .

3. Додаємо else (Інакше)

А що робити, якщо ми хочемо вивести інше повідомлення для тих, кому ще немає 18? Тут на допомогу приходить else (інакше). Він перехоплює всі варіанти, коли if не спрацював. 

const age = 16;

if (age >= 18) {
    console.log("Доступ дозволено!");
} else {
    // Цей код виконається, якщо умова вище була false
    console.log("Доступ заборонено! Тобі ще зарано.");
}

4. Кілька варіантів: else if

Життя рідко буває чорно-білим. Іноді варіантів більше ніж два. Наприклад, світлофор: червоний, жовтий або зелений. Для таких випадків ми будуємо ланцюжок перевірок. 

const trafficLight = "жовтий";

if (trafficLight === "червоний") {
    console.log("Стій!");
} else if (trafficLight === "жовтий") {
    console.log("Приготуйся!");
} else if (trafficLight === "зелений") {
    console.log("Йди!");
} else {
    // Спрацює, якщо хтось введе "синій" або щось інше
    console.log("Світлофор зламався 😱");
}

Важливо: Зверни увагу, що для перевірки рівності в JavaScript ми пишемо ТРИ знаки дорівнює: === . Один знак = потрібен лише для того, щоб покласти значення у змінну.

5. Логічні оператори (Розумні умови) 🧠

Часто однієї перевірки замало. Наприклад, щоб піти в кіно, тобі потрібно: бути старше 16 років І мати квиток . Або інший приклад: ти можеш оплатити покупку карткою АБО готівкою .

  • && (Логічне І): Вимагає, щоб УСІ умови були правдою.
  • || (Логічне АБО): Вимагає, щоб ХОЧА Б ОДНА умова була правдою. (На клавіатурі це дві вертикальні лінії над Enter). 
const userAge = 17;
const hasTicket = true;

// Використовуємо && (І)
if (userAge >= 16 && hasTicket === true) {
    console.log("Проходь на сеанс! 🍿");
} else {
    console.log("Тебе не пустять.");
}

Урок 4: Цикли (for, while) — Автоматизуємо рутину 🔄

1. Навіщо потрібні цикли?

Уяви, що тебе покарали і змусили написати на дошці 100 разів фразу: "Я більше не буду грати в ігри на уроці" . Робити це вручну — довго і нудно. Але комп'ютери обожнюють нудну роботу!

Цикл — це інструкція, яка каже комп'ютеру: "Повторюй цей шматок коду певну кількість разів, або поки не виконається певна умова". Замість того, щоб писати console.log() 100 разів, ми напишемо його лише один раз усередині циклу.

2. Цикл while (Поки)

Цей цикл працює дуже просто: ПОКИ умова є правдою ( true ), код всередині буде повторюватись.

Метафора: "Поки в коробці є шматки піци — продовжуй їсти". 

let slices = 3; // У нас 3 шматки піци

// Читається так: "Поки slices більше нуля..."
while (slices > 0) {
    console.log("З'їв один шматок 🍕");
    slices = slices - 1; // Зменшуємо кількість (інакше лопнемо!)
}

console.log("Піца закінчилась! 😭");

⚠️ Обережно: Нескінченний цикл! Якщо ти забудеш додати рядок slices = slices - 1 , кількість піци завжди буде 3. Комп'ютер буде їсти її вічно, і твоя вкладка в браузері зависне. Завжди переконайся, що умова колись стане false .

3. Цикл for (Для) — Найпопулярніший!

Цикл while зручний, коли ми не знаємо точної кількості повторень. Але якщо ми чітко знаємо, що нам треба порахувати від 1 до 5, краще використовувати цикл for .

Він виглядає трохи страшно на перший погляд, але складається з трьох логічних частин, розділених крапкою з комою ; 

// for (Початок; Умова; Крок)
for (let i = 1; i <= 5; i++) {
    console.log("Віджимання номер: " + i);
}

Розбираємо по кісточках:

  • Початок ( let i = 1 ): Ми створюємо змінну-лічильник (зазвичай її називають просто i від слова index ). Кажемо: "Почнемо рахувати з одиниці".
  • Умова ( i <= 5 ): Правило зупинки. "Крути цикл, поки i менше або дорівнює 5".
  • Крок ( i++ ): Що робити після кожного кола? Запис i++ — це короткий спосіб написати i = i + 1 . Тобто ми збільшуємо лічильник на 1.

4. Магія змінної i

Найкрутіше в циклах те, що ми можемо використовувати наш лічильник i всередині коду. Він змінюється на кожному колі! 

// Рахуємо від 0 до 3
for (let i = 0; i < 4; i++) {
    console.log(`Зараз змінна i дорівнює: ${i}`);
}
// Результат у консолі:
// Зараз змінна i дорівнює: 0
// Зараз змінна i дорівнює: 1
// Зараз змінна i дорівнює: 2
// Зараз змінна i дорівнює: 3

Урок 5: Функції — Твої власні команди ⚙️

1. Що таке функція?

Уяви, що ти купив робота-помічника. Щоб він зробив чай, тобі треба щоразу казати: "Візьми чашку, налий воду, включи чайник, кинь пакетик" . Це довго. Натомість ти можеш один раз навчити його цій послідовності і назвати її зробиЧай . Тепер достатньо просто сказати: "Робот, зробиЧай!" .

Функція — це такий самий навчений робот у твоєму коді. Це блок коду, який ми пишемо один раз, а потім можемо запускати (викликати) скільки завгодно разів у різних місцях програми.

До речі, ти вже використовував вбудовану функцію браузера — console.log() . Тепер ми будемо створювати свої!

2. Оголошення та виклик функції

Створення функції (оголошення) завжди починається зі слова function , далі йде її назва, круглі дужки () та фігурні {} , всередині яких ховається сам код. 

// 1. Оголошення функції (навчаємо робота)
function sayHello() {
    console.log("Привіт! Я твоя перша функція 👋");
}

// 2. Виклик функції (даємо команду роботу працювати)
sayHello();
sayHello(); // Можемо викликати хоч 100 разів!

⚠️ Важливо: Якщо ти просто напишеш функцію, але не викличеш її (не напишеш sayHello() з дужками), вона ніколи не виконається . Це як написати рецепт торта і покласти в стіл — торт сам не спечеться.

3. Параметри (Вхідні дані) 📥

Функція, яка завжди каже лише "Привіт" — це нудно. А що, як ми хочемо, щоб вона вітала людину на ім'я? Для цього існують параметри.

Параметр — це як отвір у блендері. Блендер (функція) знає, ЯК робити смузі. Але З ЧОГО його робити — залежить від того, що ти туди закинеш (яблуко чи банан). 

// name - це параметр (порожня коробка, яка чекає на дані)
function greetUser(name) {
    console.log(`Привіт, ${name}! Раді тебе бачити.`);
}

// Передаємо конкретні імена (аргументи) у функцію
greetUser("Олексій"); // Виведе: Привіт, Олексій!
greetUser("Марія");   // Виведе: Привіт, Марія!

Функція може приймати кілька параметрів, вони розділяються комою:

function calculateSum(a, b) {
    let result = a + b;
    console.log(`Сума чисел дорівнює: ${result}`);
}

calculateSum(10, 5); // Виведе 15
calculateSum(100, 200); // Виведе 300

4. Магія return (Повернення результату) 📤

Це найголовніше правило програмування, яке треба запам'ятати: console.log — це не результат. Це просто картинка на моніторі для програміста.

Уяви, що ти замовив піцу. Якщо кур'єр просто покаже тобі фотографію піци (це console.log ), ти не зможеш її з'їсти! Тобі потрібно, щоб він ВІДДАВ тобі піцу в руки. За це відповідає слово return . 

function multiply(a, b) {
    let result = a * b;
    return result; // Функція ВІДДАЄ результат туди, звідки її викликали
}

// Тепер ми можемо ЗБЕРЕГТИ результат у змінну (взяти піцу в руки)
let myMoney = multiply(5, 10); 

console.log(`У мене є ${myMoney} гривень`);

Як тільки код зустрічає слово return , функція одразу зупиняється (ніби каже "Моя робота закінчена, тримай результат"), і жоден код нижче всередині цієї функції більше не виконається.

Урок 6: Основи масивів. Списки стрімера 📋

1. Що таке масив?

Уяви, що ти стрімер, і тобі потрібно записати список ігор, які ти плануєш пройти за тиждень. Створювати окрему змінну для кожної гри (наприклад, game1, game2...) — це дуже довго і незручно.

Для таких випадків існують масиви (Arrays). Масив — це одна велика "коробка", в якій лежить багато значень по порядку.

2. Як створити масив?

Масив створюється за допомогою квадратних дужок [], а елементи всередині розділяються комами.

// Створюємо список ігор
const games = ["Minecraft", "Roblox", "Fortnite", "Valorant"];

console.log(games); // Виведе весь список

3. Індекси: Рахуємо з НУЛЯ 0️⃣

У кожного елемента в масиві є свій номер — індекс.
⚠️ Важливо: У програмуванні рахунок завжди починається з 0, а не з 1!

  • games[0] — це перший елемент ("Minecraft")
  • games[1] — це другий елемент ("Roblox")
  • games[2] — це третій елемент ("Fortnite")
const games = ["Minecraft", "Roblox", "Fortnite"];

console.log(games[0]); // "Minecraft"
console.log(games[2]); // "Fortnite"

4. Скільки елементів у масиві? (.length)

Щоб дізнатися, скільки всього предметів у списку, використовується властивість .length.

const games = ["Minecraft", "Roblox", "Fortnite"];
console.log(games.length); // Виведе 3

Урок 7: Методи масивів. Керуємо чатом! 🎮

1. Навіщо масивам методи?

У попередньому уроці ми навчилися створювати масив. Але на реальному стрімі список глядачів постійно змінюється: хтось заходить, хтось виходить, а донатери взагалі стрибають поза чергою.

Щоб додавати, видаляти або шукати елементи в масиві, у JavaScript є вбудовані команди — методи. Вони пишуться через крапку після назви масиву.

2. Додаємо глядачів (Push та Unshift)

Коли потрібно додати когось у наш список, ми маємо два шляхи:

📥 .push() — У кінець черги

Новий глядач зайшов на стрім і став у самий кінець списку. Це найпопулярніший метод!

const chatUsers = ["Max", "Anna"];
chatUsers.push("Oleg"); // Додаємо Олега в кінець

console.log(chatUsers); // ["Max", "Anna", "Oleg"]

👑 .unshift() — VIP-вхід на початок

Користувач закинув великий донат і автоматично потрапив на саме перше місце (індекс 0), посунувши всіх інших.

const queue = ["User1", "User2"];
queue.unshift("MegaDonater"); 

console.log(queue); // ["MegaDonater", "User1", "User2"]

3. Видаляємо глядачів (Pop та Shift)

Люди не сидять на стрімі вічно. Як видалити їх з масиву?

📤 .pop() — Видалити останнього

Викидає з масиву того, хто був у самому кінці. (Метод працює без жодних додаткових слів у дужках).

const players = ["Max", "Anna", "Oleg"];
players.pop(); // Видаляє Олега

console.log(players); // ["Max", "Anna"]

🧹 .shift() — Видалити першого

Коли чат занадто швидко летить, старі повідомлення (ті, що зверху) зникають. Цей метод видаляє перший елемент і підтягує всіх інших на крок уперед.

const messages = ["Hi", "GG", "WP"];
messages.shift(); // Видаляє "Hi"

console.log(messages); // ["GG", "WP"]

4. Пошук: Де сховався модератор?

🔍 .indexOf()

Допомагає дізнатися індекс (порядковий номер) елемента. Якщо такого елемента немає в масиві, комп'ютер поверне -1.

const viewers = ["Alex", "Admin", "Igor"];

let position = viewers.indexOf("Admin");
console.log(`Модератор знаходиться під індексом: ${position}`); // 1

let isHere = viewers.indexOf("Hacker");
console.log(isHere); // -1 (такого глядача немає)

Урок 8: Об'єкти. Твій ігровий профіль 👤

1. Що таке об'єкт і навіщо він потрібен?

Уяви, що тобі потрібно описати ігрового персонажа або стрімера. У нього є ім'я, кількість підписників, статус (онлайн/офлайн) та список улюблених ігор.

Зберігати це в різних змінних (name = "Admin"; followers = 5000;) незручно, бо дані розкидані. Об'єкт дозволяє об'єднати всі характеристики одного предмета в одну структуру.

2. Синтаксис: Ключ та Значення

Об'єкт створюється за допомогою фігурних дужок {}. Всередині ми пишемо пари "ключ: значення".

const streamer = {
  nickname: "CyberHero",    // Ключ: nickname, Значення: "CyberHero"
  followers: 1250,          // Число
  isLive: true,             // Булеве значення
  topGames: ["LoL", "CS2"]  // Масив всередині об'єкта!
};

3. Як отримати та змінити дані?

Для звернення до властивостей об'єкта найчастіше використовують крапку.

📍 Доступ через крапку (Dot Notation)

console.log(streamer.nickname); // "CyberHero"
console.log(streamer.followers); // 1250

📝 Зміна значень

Об'єкти можна змінювати навіть якщо вони оголошені через const (не можна замінити весь об'єкт, але можна змінити його "нутрощі"):

streamer.followers = 1300; // Хтось підписався!
streamer.isLive = false;    // Стрім закінчився

console.log(streamer.followers); // 1300

4. Методи об'єктів (Функції всередині)

Об'єкт може не тільки зберігати дані, а й виконувати дії. Функція, яка живе всередині об'єкта, називається методом.

const bot = {
  name: "NightBot",
  sayHi: function() {
    console.log("Привіт всім у чаті! Я ваш модератор.");
  }
};

// Викликаємо метод:
bot.sayHi(); // "Привіт всім у чаті!..."

💡 Цікавий факт: console.log() — це теж метод! console — це об'єкт, а log — його метод (функція).

Урок 10: Що таке DOM? Скануємо корабель 🛰️

1. Як JavaScript бачить твою сторінку?

До цього моменту ми працювали лише в консолі. Але як JS "спілкується" з HTML-тегами?

Для цього існує DOM (Document Object Model). Уяви, що твій HTML-код — це креслення космічного корабля, а DOM — це інтерактивна панель, де кожен гвинтик і кожен монітор є окремим об'єктом, який можна змінити кодом.

2. Пошук елементів: "Сканер" кабіни

Перш ніж змінити щось на кораблі, нам треба це "знайти". Найпопулярніші способи:

📍 Пошук за ID (найшвидший)

Використовується для унікальних елементів (наприклад, кнопка "Пуск").

const mainTitle = document.getElementById("ship-name");
console.log(mainTitle); // Виведе весь тег у консоль

📍 Пошук за класом або тегом

Якщо нам треба знайти всі лампочки в коридорі або всі пункти меню.

// Шукає ВСІ елементи з класом .status-light
const lights = document.querySelectorAll(".status-light");
console.log(lights[0]); // Перша лампочка

3. Властивість innerText: Змінюємо тексти

Урок 14: Режими корабля. Робота з класами (.classList) 🚨

1. Чому .style — це не завжди зручно?

Змінювати стилі через element.style.color = "red" зручно для однієї властивості. Але якщо при "Бойовій тривозі" треба змінити фон, рамку, колір тексту та анімацію одночасно — код стане занадто великим.

Правильний шлях: створити клас у CSS та просто додавати або видаляти його за допомогою JavaScript.

2. Основні команди classList

У кожного елемента є об'єкт classList, який має три головні методи:

  • add("назва_класу") — вмикає режим (додає клас).
  • remove("назва_класу") — вимикає режим (видаляє клас).
  • toggle("назва_класу") — як перемикач: якщо класу немає — додає, якщо є — видаляє.
const shipCabin = document.getElementById("cabin");

// Вмикаємо режим маскування
shipCabin.classList.add("stealth-mode");

// Вимикаємо аварійну ілюмінацію
shipCabin.classList.remove("emergency-lights");

// Перемикаємо щити одним кліком
shipCabin.classList.toggle("shields-active");

3. Поєднання з проєктом: Стан систем

Ми можемо поєднати це з нашими даними. Якщо в об'єкті корабля health < 20, ми автоматично додаємо клас .critical-condition до всієї панелі керування.

Урок 15: Введення даних. Як працюють форми 🔑

1. Що таке форма і навіщо вона потрібна?

До цього моменту наш «космічний корабель» лише виводив інформацію. Але справжній інтерфейс має отримувати команди від пілота.

HTML-форма (тег <form>) — це контейнер для елементів введення. Вона групує дані (ім'я, пароль, налаштування), щоб їх можна було зручно обробити разом. Без форм ми б не могли зареєструватися в соцмережах, купити квиток чи відправити повідомлення в чат.

2. Основні елементи форми

Для побудови форми ми використовуємо кілька ключових тегів:

  • <input> — універсальне поле (текст, пароль, числа).
  • <label> — підпис до поля (щоб користувач знав, що вводити).
  • <button> — спусковий гачок, який запускає обробку даних.

🛰️ Космічна порада: Завжди давай елементам id. Це твій "маячок", за яким JavaScript знайде потрібне поле серед мільйонів інших.

<!-- Приклад простої форми в HTML -->
<label for="pilot-id">Номер посвідчення:</label>
<input type="text" id="pilot-id" placeholder="Наприклад: AR-77">
<button id="scan-btn">Сканувати</button>

3. Як JavaScript дістає дані? (.value)

Коли пілот щось надрукував, цей текст потрапляє у властивість .value. Це ніби "вміст ящика", який ми можемо відкрити в будь-який момент.

// 2. Чекаємо на клік
btn.addEventListener("click", () => {
  // 3. Зазираємо всередину за допомогою .value
  const code = inputField.value; 
  
  if (code === "") {
    alert("Поле порожнє! Введіть код.");
  } else {
    console.log("Доступ отримано для: " + code);
  }
});

Урок 16: Термінал доступу. Подія submit 🖥️

1. Чому кнопка перезавантажує сторінку?

Ти міг помітити: якщо натиснути на кнопку всередині тегу <form>, сторінка на мить біліє і перезавантажується. Це стандартна поведінка браузера з 90-х років — він намагається відправити дані на сервер.

У сучасному JavaScript ми кажемо браузеру: "Стій! Я сам оброблю ці дані без перезавантаження". Для цього використовується метод preventDefault().

2. Подія submit: Обробляємо всю форму

Замість того, щоб вішати клік на кнопку, ми вішаємо подію submit на саму форму. Це дозволяє спрацьовувати коду навіть тоді, коли користувач просто натискає Enter.

const loginForm = document.getElementById("login-form");

loginForm.addEventListener("submit", (event) => {
  // 🛑 Крок 1: Зупиняємо перезавантаження
  event.preventDefault(); 
  
  // 🔍 Крок 2: Отримуємо дані (згадуємо .value)
  const username = document.getElementById("user-name").value;
  
  console.log("Форма оброблена для пілота: " + username);
});

Урок 18: Детектор помилок. Валідація даних 🛡️

1. Навіщо перевіряти дані?

Користувачі часто помиляються: вводять текст замість чисел, залишають порожні поля або пишуть занадто довгі паролі. Валідація — це процес перевірки введених даних на правильність.

2. Базові перевірки в JavaScript

Найпоширеніші сценарії, які ми маємо контролювати:

const fuelInput = document.getElementById("fuel-amount");

if (fuelInput.value === "") {
    console.log("❌ Поле не може бути порожнім!");
} else if (Number(fuelInput.value) <= 0) {
    console.log("❌ Кількість палива має бути більшою за нуль!");
} else {
    console.log("✅ Дані прийнято. Починаємо заправку.");
}

3. Регулярна валідація при введенні

Ми можемо підсвічувати помилку одразу, як тільки користувач почав писати, використовуючи подію input.

const nameInput = document.getElementById("pilot-nickname");

nameInput.addEventListener("input", () => {
  if (nameInput.value.length < 3) {
    nameInput.style.borderColor = "red"; // Сигнал помилки
  } else {
    nameInput.style.borderColor = "green"; // Все добре
  }
});

Урок 19: Бортовий журнал. Фідбек користувачу 📢

1. Чому alert — це погано?

Команда alert() зупиняє роботу всієї сторінки, поки користувач не натисне "ОК". У сучасному вебі (та в кабіні пілота) це неприпустимо. Гарний інтерфейс має виводити повідомлення прямо на екран, не заважаючи іншим процесам.

2. Динамічний статус-бар

Найпростіший спосіб дати фідбек — змінити текст та колір спеціального блоку статусів.

const statusBar = document.getElementById("status-bar");

function showMessage(text, isError) {
  statusBar.innerText = text;
  statusBar.style.color = isError ? "#ff4d4d" : "#2ecc71";
  
  // Через 3 секунди очищуємо статус
  setTimeout(() => {
    statusBar.innerText = "Система готова";
    statusBar.style.color = "white";
  }, 3000);
}

3. Візуальні ефекти (Анімація через класи)

Ми можемо додати клас, який змусить кнопку або індикатори "блимати", якщо сталася помилка.

const engineBtn = document.getElementById("engine-btn");

if (energy < 20) {
  engineBtn.classList.add("shake-animation"); // Клас з CSS анімацією
  showMessage("Низький рівень енергії!", true);
}
